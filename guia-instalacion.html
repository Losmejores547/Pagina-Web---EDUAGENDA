Volver a la App

¿Cómo abrir la aplicación ahora mismo?

Opción más fácil: Usa el botón "Publish" (pestaña arriba en esta plataforma). La app se publica en segundos y recibes una URL pública lista para compartir desde celular o computador.

🖥️ Ver la app en esta misma plataforma (Preview)

Si estás trabajando en Genspark u otra plataforma de edición, haz clic en el botón "Preview" o "Open in browser" para ver la app funcionando en tiempo real.

💻 Ver en tu computador con VS Code

1
Descarga los archivos del proyecto Descarga todos los archivos (index.html, carpetas css/ y js/) en una carpeta llamada EduAgenda.
2
Abre la carpeta en VS Code 
File → Open Folder → Selecciona la carpeta EduAgenda
3
Instala Live Server (si no lo tienes) 
Ctrl+Shift+X → Buscar "Live Server" → Install
4
Inicia el servidor Clic derecho sobre index.html en el panel izquierdo → "Open with Live Server"
Se abre automáticamente en: http://127.0.0.1:5500/index.html
¡Importante! No abras index.html haciendo doble clic en el archivo. Siempre usa Live Server o un servidor web. Si abres el archivo directamente, las llamadas a la API de base de datos no funcionarán.

📱 Ver en el celular (misma red WiFi)

Con Live Server activo en VS Code, desde tu celular abre el navegador y escribe la IP de tu computador seguida del puerto 5500:

Ejemplo: http://192.168.1.10:5500/index.html
(La IP la ves en VS Code en la barra inferior, o busca tu IP local en Configuración de Red)

1. Arquitectura del Proyecto

EduAgenda es una aplicación web estática (SPA – Single Page Application) construida solo con:

  • HTML5 – Estructura y contenido
  • CSS3 – Estilos y diseño responsivo
  • JavaScript ES6+ – Lógica, navegación y datos
¿Por qué no usa Python o Java? Esta app web funciona completamente en el navegador del usuario, sin necesitar un servidor. Los datos se guardan en la nube a través de una API REST. Esto la hace más rápida, barata de hospedar (¡gratis!) y funciona desde cualquier dispositivo.

Flujo de Datos

Usuario (navegador)
    ↕ HTML/CSS/JS (tu código)
    ↕ fetch() – llamadas HTTP
    ↕ API REST de Tablas (base de datos en la nube)
         tablas: usuarios, materias, tareas, evaluaciones, notas, faltas, mensajes, horarios

    Además:
    JavaScript ↔ Google Gemini API (IA – opcional, API Key gratuita)

3. Base de Datos (Gratuita y en la Nube)

EduAgenda usa una API REST de tablas que almacena los datos en la nube automáticamente. No necesitas instalar MySQL, MongoDB ni ninguna base de datos local.

Tablas del sistema:

usuariosEstudiantes, docentes, acudientesnombre, correo, rol, contrasena
materiasAsignaturas del colegionombre, descripcion, id_profesor, color
tareasTrabajos y deberestitulo, prioridad, fecha_entrega, estado
evaluacionesExámenes y quicestitulo, tipo, porcentaje, fecha_evaluacion
notasCalificacionesid_estudiante, calificacion, id_evaluacion

Cómo funciona la API (ejemplo):

// Obtener todas las tareas
fetch('tables/tareas?limit=100')
  .then(r => r.json())
  .then(data => console.log(data.data)); // array de tareas

// Crear nueva tarea
fetch('tables/tareas', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    titulo: 'Tarea de Matemáticas',
    prioridad: 'alta',
    fecha_entrega: '2025-12-20',
    estado: 'pendiente'
  })
});

4. Explicación de cada Módulo JavaScript

📁 utils.js – Funciones de Ayuda

Contiene herramientas usadas en toda la app:

  • showToast(mensaje, tipo) – Muestra notificaciones emergentes
  • abrirModal({titulo, cuerpo, onConfirm}) – Abre ventana modal
  • formatearFecha(fecha) – Convierte fechas a formato legible
  • fechaRelativa(fecha) – "Hoy", "Mañana", "En 3 días"
  • calcularPromedio(valores) – Promedia un array de notas
  • Storage.get/set/remove(key) – Guarda datos en el navegador
  • markdownToHtml(texto) – Convierte texto markdown a HTML (para IA)

📁 auth.js – Autenticación

Maneja el login, registro y sesión:

  • Las contraseñas se guardan con btoa() (codificación básica base64)
  • La sesión se guarda en localStorage
  • Hay 3 cuentas demo: estudiante, docente, acudiente
  • Para cambiar a mayor seguridad, reemplaza btoa() por hash SHA-256

📁 api.js – Comunicación con la Base de Datos

Centraliza todas las llamadas HTTP:

  • API.get(tabla, params) – Listar registros
  • API.create(tabla, datos) – Crear registro
  • API.update(tabla, id, datos) – Actualizar
  • API.delete(tabla, id) – Eliminar

📁 app.js – Controlador Principal

Controla la navegación entre páginas:

  • cambiarPagina(nombre) – Navega entre módulos sin recargar
  • Al cambiar de página, carga automáticamente los datos correspondientes

📁 ia-tutor.js – Tutor con Inteligencia Artificial

Conecta con la API de Google Gemini:

  • Mantiene historial de conversación
  • Crea un prompt personalizado con los datos del estudiante
  • Convierte Markdown a HTML para mejor presentación
  • Guarda la API Key en localStorage

5. Configurar la IA (Google Gemini – GRATIS)

1
Ir a Google AI Studio Ve a aistudio.google.com/app/apikey
2
Iniciar sesión con tu cuenta de Google Cualquier cuenta de Gmail funciona. No necesitas tarjeta de crédito.
3
Crear API Key Haz clic en "Create API Key" → "Create API Key in new project". Copia la clave generada.
4
Pegar en EduAgenda Ve a la sección "Tutor IA" en la app, pega tu API Key en el campo correspondiente y haz clic en "Guardar".
El plan gratuito de Gemini incluye: 15 solicitudes por minuto, 1 millón de tokens por minuto, 1500 solicitudes por día. ¡Más que suficiente para uso académico!
Importante de seguridad: La API Key se guarda en el navegador del usuario (localStorage). No la compartas públicamente. Para producción real, considera usar un backend que oculte la clave.

6. Cómo Personalizar el Código

🎨 Cambiar colores

Abre css/style.css y modifica las variables al inicio del archivo:

:root {
  --primary: #3B5BDB;    /* Azul principal – cambia este color */
  --secondary: #40C057;  /* Verde – aprobado, éxito */
  --accent: #FD7E14;     /* Naranja – advertencias */
  --danger: #FA5252;     /* Rojo – errores, reprobado */
  --bg: #f0f2f8;         /* Fondo de la app */
}

Por ejemplo, para hacer la app verde esmeralda:

--primary: #00897B;   /* Verde esmeralda */
--secondary: #26A69A; /* Teal */

📝 Cambiar el nombre de la app

En index.html, busca y reemplaza todas las ocurrencias de "EduAgenda" con el nombre deseado. También cambia el <title> en la línea 5.

🏫 Cambiar la escala de calificación

En js/utils.js, función claseNota():

function claseNota(nota) {
  const n = parseFloat(nota);
  if (n >= 4.0) return 'alta';   // ← Cambiar a >= 8 para escala de 10
  if (n >= 3.0) return 'media';  // ← Cambiar a >= 6
  return 'baja';
}

Para escala de 0-10, cambia también los inputs min/max de calificación en js/notas.js.

📚 Agregar nuevos campos a las materias

En js/materias.js, función abrirFormulario(), agrega campos al HTML del formulario, y en el objeto datos incluye los nuevos valores.

🤖 Cambiar el comportamiento del Tutor IA

En js/ia-tutor.js, función _llamarGemini(), modifica la variable systemPrompt para cambiar la personalidad y comportamiento del tutor.

🎭 Cambiar el modelo de IA

// En js/ia-tutor.js, línea que dice:
const url = `...models/gemini-1.5-flash:generateContent?key=${this._apiKey}`;

// Puedes cambiar a:
// gemini-1.5-pro  (más potente, pero más lento)
// gemini-2.0-flash (más nuevo y rápido)

📱 Opción B: Instalar como App en el Celular (PWA)

Una PWA (Progressive Web App) se instala en el celular igual que una app normal, pero sin pasar por la Play Store.

Para habilitarla, agrega estos archivos al proyecto:

1. Crear manifest.json:

{
  "name": "EduAgenda",
  "short_name": "EduAgenda",
  "description": "Gestión Académica Inteligente",
  "start_url": "/index.html",
  "display": "standalone",
  "background_color": "#3B5BDB",
  "theme_color": "#3B5BDB",
  "icons": [
    {
      "src": "icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}

2. Crear service-worker.js (para modo offline):

const CACHE_NAME = 'eduagenda-v1';
const ARCHIVOS = [
  '/', '/index.html',
  '/css/style.css', '/css/responsive.css',
  '/js/utils.js', '/js/app.js'
];

self.addEventListener('install', e => {
  e.waitUntil(
    caches.open(CACHE_NAME).then(c => c.addAll(ARCHIVOS))
  );
});

self.addEventListener('fetch', e => {
  e.respondWith(
    caches.match(e.request).then(r => r || fetch(e.request))
  );
});

3. Registrar el Service Worker en index.html (antes de </body>):

<script>
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/service-worker.js');
}
</script>

4. Agregar al <head> de index.html:

<link rel="manifest" href="manifest.json">
<meta name="theme-color" content="#3B5BDB">
<meta name="apple-mobile-web-app-capable" content="yes">

Cuando los usuarios visiten el sitio en Chrome (Android) o Safari (iPhone), verán la opción "Agregar a pantalla de inicio".

9. Preguntas Frecuentes

❓ ¿Los datos se pierden si cierro el navegador?

No. Los datos (materias, tareas, notas, etc.) se guardan en la base de datos en la nube a través de la API. Solo la sesión del usuario puede cerrarse, pero los datos permanecen.

❓ ¿Funciona sin internet?

Si instalas como PWA con Service Worker, la app puede cargar offline, pero no podrá guardar ni leer datos sin conexión (requiere backend adicional).

❓ ¿Cómo agrego más usuarios?

Cualquier persona puede registrarse en la app usando el formulario de "Registrarse". O puedes crear cuentas desde el panel de administración de la base de datos.

❓ ¿Puedo cambiar el idioma?

Busca todos los textos en index.html y los archivos JS y reemplázalos. Los textos de la interfaz están en los archivos HTML y JS directamente.

❓ ¿Cómo cambio la nota mínima aprobatoria?

En js/notas.js, busca prom >= 3.0 y cambia el 3.0 por tu nota mínima. También en js/utils.js función claseNota().

❓ ¿Puedo usar otra IA además de Gemini?

Sí. En js/ia-tutor.js, función _llamarGemini(), cambia la URL y el formato del cuerpo (body) según la API que quieras usar. Opciones gratuitas: Groq API (Llama 3), Together AI.

❓ ¿Cómo hacer un respaldo de los datos?

Desde la consola del navegador puedes usar la API para exportar datos a JSON:

fetch('tables/tareas?limit=1000')
  .then(r => r.json())
  .then(d => console.log(JSON.stringify(d.data)));

❓ ¿Cómo depurar errores?

Abre las Herramientas de Desarrollador del navegador (F12), ve a la pestaña Console. Los errores aparecen en rojo. Los módulos JS muestran "✅ módulo.js cargado" si están bien.
